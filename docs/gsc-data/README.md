# Google Search Console Export Data

Place the exported CSV files from Google Search Console here:
- `Queries.csv`
- `Pages.csv`
- (Optional: other exported CSVs such as Countries.csv, Devices.csv)

### Export Steps:
1. Open Google Search Console: https://search.google.com/search-console
2. Select property: `pakbenefits.com`
3. Click **Performance** (Search results) in the left sidebar
4. Set Date filter to **Last 28 days** (or Last 3 months)
5. Click **Export** (top right) -> **Download CSV**
6. Extract the downloaded ZIP file and paste `Queries.csv` & `Pages.csv` into this folder.
